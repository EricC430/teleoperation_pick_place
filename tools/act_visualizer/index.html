📖 如何診斷 ACT 模型為何失誤？

  1. 比較 ROI 注意力比例：只在杯子可見時框選 ROI，再補接近與接觸階段的框。單一框只計算該幀，多個框只在首尾標註之間插值；區間內的可見性仍需人工確認。比例以原始 attention 權重計算，會受 ROI 面積影響；沒有固定的失敗門檻。舊版分析資料需重新匯出。
  2. 觀察 Layer Latent：Cosine 相似度與 entropy 可以協助挑出變化大的片段，但不能單獨證明模型遺失物體位置。Encoder 已混合相機與關節資訊，decoder 的 token 權重也不等於相機的因果重要性。
  3. 比較 Action Chunk：Query t=0 / t=20 / t=50 是預測序列中的偏移量。此工具每幀重新推論；曲線不是 N=30 或 N=100 真機實際執行的 action。判斷腕部影像是否有幫助，需再做凍結／替換影像的對照實驗。
