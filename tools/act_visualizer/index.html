📖 如何診斷 ACT 模型為何失誤？

  1. 檢查目標注意力集中度（AoTR）：點擊「✏️ Draw ROI」在第 0 幀以滑鼠框選紙杯，再跳至接觸幀框選一次，點擊「⚡ Interpolate ROI」。觀察下方曲線何時跌破 30%（紅色標記）。若接近物體時 AoTR 急遽下滑，表示模型目光被機械手臂陰影或桌面邊緣吸引。
  2. 拆解 Layer Latent 特徵流動：切換至「🧬 Layer 1~4 Latent Progression」。如果 Layer 1~2 的 Cosine 相似度很高但在 Layer 3 劇烈下降，或 Layer 3 的 Attention 呈現擴散（Entropy 偏高），代表模型在深層推論時遺失了目標物空間位置。
  3. 觀察 Action Chunk 未來意圖：在頂部切換「Query t=0」與「Query t=20 / t=50」。若即時動作看著杯子，但 t=50 的注意力偏離到桌面其他地方，說明模型預測的軌跡意圖本身已有先天的方向偏差。
