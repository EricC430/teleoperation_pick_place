# 共同桌面、底座位姿與重力聯合解算

## 結果

已把下列項目明確納入同一個離線模型：
- 座標紙定義共同平面 z=0。ID1、ID4在平面上；ID5、ID6共用2.5–3mm紙板高度。每張標記僅可在平面內轉動，不能各自浮在不同高度或傾斜。
- 手臂底座重新估計六維位姿，不再固定沿用10/14結果。
- 桌面相對水平、底座相對水平分開參數化；重力經座標變換進入各姿勢的重力矩計算，不再直接假設沿底座-Z。
- 使用照片CSV的實測state_*；f60與結尾f50仍未參與擬合，兩個已知拍照期間漂移的停點維持排除。

三種模型均已完成收斂複核；首輪未收斂候選已由相同訓練資料的暖啟動重新解算。最後結果在refined/report.json。

| 共同平面模型 | 保留f60中位誤差 | 最大誤差 |
|---|---:|---:|
| 原下垂補償 | 7.83px | 14.10px |
| 重估補償係數 | 3.71px | 7.21px |
| 放寬歷史量測先驗 | 3.75px | 7.19px |

依f40開發組RMS選擇「重估補償係數」後，結尾f50的中位誤差6.09px、最大8.52px。這仍不是可忽略誤差，也不是絕對指尖毫米精度驗收。

## 傾角與底座位姿不是新實測值

主候選估計桌面相對重力傾角約3.64度、底座相對重力約1.10度，底座相對紙面RPY約[0.31,4.63,1.81]度，底座位置約[10.4,0.3,136.9]mm。這些是同時配合相機、補償係數、標記微小XY修正的模型推估，不能據此宣稱現場桌面或底座就是這些數字。

歷史紀錄是10/13 level_check CSV，以及solve_link_markers.py內10/15註記。其量測軸、正負號與時點不完全一致；此次採桌面傾角大小2.75±0.4度、底座傾角大小0.45±0.35度作歷史先驗，另做放寬先驗對照。其方向初值依既有座標變換選定，沒有新的10/18水平儀量測驗證。不得將這些先驗稱為今天的精確量測。

第一版只用軟約束時，保留原補償的模型把傾角推到約8度，因此不能採用。分開水平座標、加入角度範圍、並只對影像殘差使用robust loss後，原補償候選仍碰到上界。重估補償後雖可收斂，結果仍受先驗與模型假設影響；紙板高度也傾向2.5mm下界。不能讓模型用不合理傾角去吸收其他幾何誤差。

資料本身的尺度正規化Jacobian秩為27/30。模型還包含紙面內標記XY修正，因此座標規範自由度等需靠位置先驗固定；這不等於每個底座、桌面、重力參數都已由影像獨立量出。這一限制與殘差同時保留在report.json。

## 目前能做與不能做的結論

- 底座與桌面傾角現在已在數學模型中分開處理，但尚未獨立量測驗證。
- 納入共同平面與傾角後，仍有跨姿勢與首尾重拍誤差；不能把先前偏差單純歸因於漏掉桌面傾角。
- 現有照片已足夠做目前的模型比較，不要求追加照片。標記仍可以收走。
- 若要把兩個實際傾角定量分開，下一個必要資訊是當前底座與桌面沿座標紙+X、+Y方向的水平儀讀數，以及正負號定義；不是再拍更多ArUco照片。量測應對準實際承載面並註明方向，不把翹起紙張當整張桌面的方向。
- 不採用這次推估值更新正式相機外參、底座標定或PID。任何後續採用都須保留對應FK/重力/補償模型，不能只替換相機JSON。

## 驗證與檔案

已通過底座/水平/紙面重力轉換的代數檢查、重力矩對重力向量的線性基底檢查、共同平面與紙板高度檢查，並核對三個候選均收斂、仍保留相同11張f60影像。

- refined/report.json：最終複核結果、來源雜湊、限制與參數。
- bounded_physical/report.json：第一版有角度範圍的結果，包含當時未收斂狀態，不能取代refined版本。
- report.json：最早軟約束診斷，僅用來保留不合理傾角的失敗證據，不供採用。
- scripts/solve_wrist_common_plane.py：可重跑的離線模型，沒有硬體控制。
