# 2026-11-11 實作紀錄：寶特瓶的模擬物體（S9 管線）

參與：柏宇（量測、判斷）、Claude（AI，實作與檢查） ｜ 性質：實作＋量測，在 Windows 筆電上做，**沒有在 Isaac Sim 執行**

## 問題

S9 管線只能處理杯型物體，所以寶特瓶的資料不能拿來做擴增。寶特瓶又有兩個優點：

- 10/21 補錄的 75 集示範在 10/14 之後，符合 Eric「只用 10/14 之後的資料」的範圍（S9 §0）。用示範當來源，也不會有拿閉環 c 點擴增、又在 c 點評估的污染問題。
- 10/22 那場閉環 23/36，有 13 集失敗，而且失敗原因標得很細。拿來驗證重播的一致率，比紙杯（34/36，只有 2 集失敗）更有鑑別力。

S10 §6 把寶特瓶列為非目標，那是 S10 的範圍。這份是 S9 物體的擴充，柏宇決定先做。

## 結論

1. **建好了寶特瓶物體**：做法是把外形輪廓旋轉成實心網格。質量、重心、慣量照空心瓶計算，另外寫進 USD。
   - 本機只驗證了網格：封閉（0 條開放邊）；網格算的體積 664.4 ml，輪廓算的 666.3 ml。
   - USD 寫入、物理重播、穿透檢查**都還沒在 4090 上跑過**。
2. **外形用柏宇量的尺寸**（下表）。網路上查不到單瓶尺寸（§1）。
3. **體積合理性**：模型的實心體積約 666 ml，比標示 590 ml 多約 13%。
   - 沒建收腰時是 753 ml。加上收腰後差距才縮到這個程度。
   - 每項量測改動一個合理誤差，體積最多變 ±17 ml（瓶身周長 ±0.5 cm），單一量測誤差解釋不了 76 ml 的差。
   - 推論：差距主要來自模型沒建的東西，也就是螺旋凹槽、瓶壁、凹底、頂部空間。
   - 這支瓶子實際的外部體積不知道，所以 590 ml 不能當「模型應該等於多少」的標準答案。
4. **要準的是夾取高度附近的尺寸，不是體積**。柏宇說示範時手指多半夾在 12–18 cm `[柏宇說]`。這一段在模型裡是直筒、直徑 6.94 cm，所以**瓶身周長是最該量準的一項**；它剛好也是體積最敏感的一項。肩部外形（18.2 → 20.7 cm）比較不急。

## 3. 實作

| 檔案 | 內容 |
|---|---|
| `sim/bottle_mesh.py`（新） | 外形輪廓 `profile()`，可以用 `body_points` 直接給「高度 → 直徑」的控制點；`bottle_mesh()`（uv 規則跟杯子一樣）；`mass_props()`（瓶身的 PET 平均鋪在外表面、瓶蓋當實心圓柱、可選的水）；`depth_inside()`（給穿透檢查用）；自我測試 |
| `sim/dr_objects_bottle.json`（新） | `bottle_ref` 的尺寸與每個數字的來源。**刻意不放進 `sim/dr_config.json`**：`dr_collect.py` 會把清單裡每個物體 × 每集都跑一遍，放進去的話，Eric 跑紙杯時就會拿紙杯軌跡去夾寶特瓶 |
| `sim/dr_objects.py` | `"shape": "bottle"` 分支；USD 另外寫入重心和慣量；prim 名稱沿用 `/PaperCup/...`，所以 `physics_replay.py` 和 `dr_render.py` 不用改。紙杯的路徑不變 |
| `sim/penetration.py` | 寶特瓶是實心的，沒有壁也沒有內腔：`vol_mm3` ＝ 連桿陷進實心的體積；`through` ＝ 有任何一點深於 `bottle_deep_mm`（預設 1.0，比照紙杯壁厚，**門檻未定**）。連桿的距離門檻放寬到瓶高＋10 cm，否則夾瓶蓋時（c33、c36）手指在 25 cm 外，會被當成沒穿透 |
| `scripts/dr_collect.py` | `--objects <json>`：換掉工作目錄 config 副本裡的 `objects.geometry`（有給的話也換 `expected_config`）。不是 `stand` 的集跳過 |
| `scripts/prep_closed_loop_replay.py` | 把 `object_orientation` 寫進 `episode.json` |

順帶發現 `已查證`：`dr_collect.accepted()` 在沒有穿透結果時預設當成「乾淨」（`.get("clean", True)`）。原本的 `penetration.py` 遇到非杯子的物體會讀不到 `top_dia` 而失敗，結果就是**沒有量、照收**。改完之後寶特瓶會有結果；但「穿透檢查失敗時照收」這個預設本身沒改，要不要改由 Eric 決定。

## 4. 執行（4090）

```bash
python3 scripts/prep_closed_loop_replay.py ~/isaaclab_volume/dr/src/<run> rollout_omx_b4a_plastic_bottle_136_augfl_fldrop30_100k_nas1_te-001_20261022_104207
python3 scripts/dr_collect.py --work ~/isaaclab_volume/dr/<name> --source ~/isaaclab_volume/dr/src/<run> \
  --objects sim/dr_objects_bottle.json --all-outcomes --steps objects,validate
```

`--all-outcomes` 是為了把實機失敗的集也跑進去。驗證時兩個方向都要算：實機成功、模擬也成功的比例；實機失敗、模擬也失敗的比例。
