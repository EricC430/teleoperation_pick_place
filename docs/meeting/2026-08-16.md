## 二、本次討論

### 1. 簡報研討與 8/18 報告大綱
- 簡報連結：[大專生計畫0818](https://docs.google.com/presentation/d/1QfkZ-bIG-RjK2q-6LHQZwigp_3gi-VTXZVmXnsWuTuw/edit?usp=sharing)
- 報告架構確認：
  1. 計畫定位與轉向（由模擬 RL 轉向遙操作模仿學習，鎖定 SO-ARM 平台）
  2. 手臂未到期間之細項決定（ACT baseline、任務成功判準、物體清單、前置管線）
  3. 測試結果標記流程（兩軸三步驟：Step 0 有效性過濾、Step 1 Outcome、Step 2 Mechanism）
  4. 手臂到貨後四階段推動規劃（Phase A 基礎管線 → Phase B 室內基準與變因 → Phase C 室外撿拾 → Phase D 多模態觸覺）
  5. 待決提問清單（手臂歸期、自走車載具定位、相機配置、耗材採購、觸覺 vs 戶外、結案成果期待）

### 2. 失敗機制補充
- 在 Step 2 `mechanism` 失效機制標籤中，補充 **`repetition_loop`（死循環重複動作）**。
- 用於捕捉策略在推論時陷入局部極值、於相近軌跡區間不斷來回擺動或原地重試的行為，與 `stalled`（完全靜止）及 `drift`（單向漂移出界）清楚區隔。

### 3. 紀錄的 Dataset Schema 規格確認
- **`<frame>` 層級特徵**：
  - `action`：關節角度指令（絕對角度，或後續評估之表示法）
  - `observation.state`：當前關節狀態
  - `observation.images.top`：第三視角全局相機影像
  - `observation.images.wrist`：手腕相機影像
  - `timestamp`、`frame_index`、`episode_index`、`index`、`task_index`
- **`<episode>` 層級 Metadata**：
  - `object_name`（物體名稱）、`env_light`（光線條件）、`env_bg`（背景環境）、`object_pos`（初始座標/格位）、`valid`（1/0）、`outcome`（success/no_grasp/dropped/misplaced）、`mechanism`（失效機制標籤）、`quality`、`operator`（操作者）、`record_ts`（錄製時間戳記）等。

### 4. 開環評估錄製數量
- 開環評估（Open-loop Rollout）錄製數量定為 **10 筆**。
- 基準模型資料配比：鋁罐 + 室內固定光源 + 平面桌面，錄製 60 筆軌跡（**50 訓練 / 10 開環評估**）。

### 5. 訓練集與評估集的物體初始位置配置
- 訓練集與評估（開環與閉環）集之物體放置位置，需事先規劃均勻之隨機分布（Seeded 30 組配置）。
- 於場景常數與參數設置步驟統一定義，避免評估時人為偏置。

### 6. 回合 Schema 標記腳本
- 針對 episode metadata 與三步驟標記（Step 0~2），規劃撰寫自動/輔助標記腳本，簡化評估日誌記錄流程。

### 7. ACT 失敗原因與泛化表現調查
- 柏宇分享：參考機械系牙套報告影片，調高 **chunking 長度（Action Chunking horizon）** 有助於提升策略之泛化與平滑度，後續可作為超參數消融實驗之方向。
