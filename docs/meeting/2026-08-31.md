### 步驟 1｜🔴 X3P 線互換檢查（分岔點）

**要找的是：有沒有某一條「只需要 100 mm 卻用了 180 mm」的線，可以跟卡住的那條對調。**
零成本、不用等貨。成立就當場解掉 D023。

| | 路線 A：互換成立 | 路線 B：不成立（已確認實驗室無備用線） |
|---|---|---|
| 當場做 | **換線**（🔴 **必須是換線，不是改走線**——改走線會讓 D023 的保守工作區豁免作廢） | 量出**需要的長度**、拍**線材銘牌／料號**、確認接頭型式 |
| 接著 | 走步驟 2 → 3 → 4 → 5 → 6 → 7 | **當天就下單購線**（線上電商／代理商採智科技）。**A8 錄製今天不做** |
| 今天還能做 | 全部（包含 S1/S2、相機外參、偏移量、D405、A6/A7、pilot A8） | 步驟 2（S1量測）、3（偏移量）、4（D405）、5（相機外參＋順序凍結） |

> ⚠️ **把換線與改走線分清楚，這不是措辭問題。**
> 換長線＝只把空間加回來（單調放寬）→ 先前選在保守區內的配置點仍然可達。
> 改走線＝改變「哪些方向」被限制 → **可能在某個方位角拿掉空間**，先前的配置點就不保證可達了。

### 步驟 2｜量三個數字（S1 `reach_logger.py` + S2 `sample_placements.py`，換完線立刻做）

> 🔴 **D023 §2026-08-31 `[Eric說]`：「33–43」不是環帶、不是方位角相依。**
> **43 = 手臂伸直最遠可及、只能側夾；33 = 還能從上方下爪的最遠距離。**
> 舊的「裁決 (a)/(b)」整段作廢。今天要**分開量 top-down 與 side-only 兩個外徑**。
>
> 🔴 **D026：S1 `reach_logger.py` 已實作完成！** 內建基於 `assets/omx_f/omx_f.urdf` 的純 Python 正向運動學（FK）（經 `urchin` 測試驗證）。
> 現場執行時會先啟動 5-pose FK 實體驗證（以捲尺比對桌面座標，若偏差 >1cm 可 fallback `--fk-fallback tape`，雙重保險）。

**執行指令：**
```powershell
# 1. 執行 S1 量測
uv run python scripts/reach_logger.py --mode teleop
```
**按鍵說明**：
- `o`：記錄 `r_outer`（top-down 可夾最遠點，可在不同角度採多點）
- `s`：記錄 `r_outer_side`（只能水平側夾的最遠可及半徑，供參）
- `i`：記錄 `r_inner`（還能從上方下爪的最小半徑）
- `a`：記錄傳輸線限制的方位角極限點（掃描記錄受限邊界）
- `r`：記錄基準點（mat reference，0° 前向線方向）
- `q`：存檔並退出

**產出檔案**：
- `analysis/reach_log_2026-08-31.csv`
- `analysis/reach_summary_2026-08-31.json`
- `analysis/reach_plot_2026-08-31.png`

**立即執行 S2 產出凍結抽樣清單**：
```powershell
# 2. 讀取 S1 產出，直接生成抽樣配置清單（50 train, 10 eval-open, 30 eval-close）
uv run python scripts/sample_placements.py `
    --from-summary analysis/reach_summary_2026-08-31.json `
    --margin 2.0 --d-min 2.0 --seed 20260831 --label campaign_A_pilot_2cam
```
**產出清單**：
- `configs/placements/camp_campaign_A_pilot_2cam_train.csv` (50 點)
- `configs/placements/camp_campaign_A_pilot_2cam_eval-open.csv` (10 點)
- `configs/placements/camp_campaign_A_pilot_2cam_eval-close.csv` (30 點)

| # | 量什麼 | 怎麼量 | 為什麼重要 |
|---|---|---|---|
| 1 | **傳輸線限制哪個方位角範圍** | S1 按 `a` 記錄邊界，全伸展下左→右掃一遍 | 決定 §3 的 azimuth 扇形 |
| 2a | **`r_outer`（top-down 可夾）** | S1 按 `o` 記錄，找「還能從上方／斜向擺出可夾姿態」的最遠半徑 | **這是進 §3 的外徑**。⚠️ 構得到 ≠ 夾得起來 |
| 2b | **`r_outer_side`（只能側夾）供參** | S1 按 `s` 記錄，手臂伸直、只能水平側夾的最遠半徑 | 記錄用，**不進 §3**，作為 top-down/side 差距的證據 |
| 3 | **還能下爪的 r_min** | S1 按 `i` 記錄，由內往外找「夾爪還擺得出可夾姿態」的最小半徑 | 內徑 |
| 4 | **基座原點 ＋ 一條 0° 前向線** | S1 按 `r`，在桌面標出 pan 軸正下方的點及正前方直線 | 搭配極座標紙對位，對齊實體座標與抽樣點 |
