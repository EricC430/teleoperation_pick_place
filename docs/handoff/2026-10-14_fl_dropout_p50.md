## 為什麼

- fldrop30 的離線手腕修正比例中位數從 +0.05／+0.21 升到 +0.47／+0.74，front-left 跟隨比例下降（`2026-10-13_fl_dropout.md`「離線結果」）。
- 閉環 30/36，比 ntcfA1aug 的 25/36 多，但配對 p = 0.18（同一份檔案「閉環結果」）。
- p = 0.3 實際只遮了 2.8% 的樣本。加量到 0.5（約 4.7%），看效果會不會跟著變大 `[柏宇決定]`。
  窗口內手腕畫面都看得到杯子（8/8 集），所以 p 調高不會出現「完全沒有杯子資訊」的樣本。

## 步驟

200 步的 smoke test 在 p30 已經跑過，同一份程式、同一份 config，這次不用再跑。
p30 的 100k 在 4090 花了 8 h 48 m（`docs/meeting/2026-10-14_fldrop_open_loop.md` §1），這次預期差不多。

```bash
git pull
./scripts/run_container.sh python scripts/train_fl_dropout.py --fl-p 0.5 --fl-window 30 \
    --config_path configs/train_omx_cup_uvc60_normal_tightcut_far_A1_aug_fldrop.yaml \
    --output_dir /workspace/data/train/cup_uvc60_normal_tightcut_far_A1_aug_fldrop_p50_w30 \
    --job_name act_omx_cup_uvc60_normal_tightcut_far_A1_aug_fldrop_p50_w30
```

開跑後確認：
- log 裡的 `front-left approach dropout: {...}` 是 `'p': 0.5`。

  `episodes_without_close` 空的、`expected_masked_fraction` 約 0.047（p30 是 0.0282）。
- **`--resume` 時要再帶 `--fl-p 0.5 --fl-window 30`**。
