# S3 — 擺放對位（極座標墊產生器）

**目標檔案：`scripts/make_placement_mat.py`**
**正本依據：`docs/decisions.md` D023 第 3 支腳本、D024（三份清單）、S1 §6（`azimuth_offset_deg`）、S2（`x_cm/y_cm` 欄）**

---

## 1. 這支腳本要解決的問題

S2 抽出了 `(r, θ)` 與對應的 `(x_cm, y_cm)`。**問題是怎麼把實體物件真的放在那個座標上，而且每次、每個模型都放得一樣。**
放不準 → 「seeded placement」就沒意義，跨模型可比性也沒了。

**做法（`[Eric決定]` 2026-08-31）：印一張「只有刻度的通用座標紙」，人拿尺照 S2 的 `x_cm, y_cm`
把每個點一次性標到紙上，之後不再重標。**

- 座標紙**不含**任何 campaign 的點——它是通用的、可重複使用的，跟哪一批 S2 清單無關。
- 標點是**一次性**的：拿尺把 90 點（train 50 + eval-open 10 + eval-close 30）一次全部畫上去，
  拍照存證，之後每回合只是「找到 id、放物體」。**不要每回合重新目視內插**——那會把 seeding 想
  消除的人為誤差重新加回來。
- 毫米尺精度 ≈ 0.05 cm，遠低於擺放重複精度地板（~1 cm）與 `d_min`（2 cm），**夠用**。
- 腳本**可選** `--placements` 直接把點畫進 PDF（等 S1 實測數字出來、有正式 S2 清單後用）；
  但預設產出是**空白刻度紙**，現在就能印。

## 2. 🔴 會毀掉資料的地雷

### 2-1 墊子留在畫面裡 = 它變成背景常數

D023 原文：**「A mat left in frame becomes part of the background — a scene constant baked into
every demo.」**
→ **用墊子把物體擺好，然後把墊子抽走，再開始錄。** 每回合約 10 秒。
→ 操作卡第一行就要印這句。

### 2-2 印表機會縮放，A4 拼貼會累積

A4「實際大小 / 100%」在多數印表機驅動裡**不是預設**。縮放 96% 的墊子會讓每個點系統性偏內；
多張 A4 拼貼時每張的縮放誤差會沿拼縫累積。
→ **每一頁都印一條標「10.0 cm」的校驗尺**。操作卡第一步：「拿捲尺量每一頁的校驗尺，不是
10.0 cm（±0.5 mm）就重設印表機為 100% 重印。」
→ 拼貼時對齊**十字對位記號**（見 §4），不要對齊紙邊。

### 2-3 原點對不準比刻度不準更嚴重

墊子的原點（笛卡兒 0,0 = 極點）必須對到**手臂基座的旋轉中心**
（= `omx_f` URDF 的 `joint1` 軸 = S1 FK 的 base 原點），不是基座外殼的邊。
→ 中央頁要有十字準星 ＋ 一段說明；`docs/experiment_spec.md` §3 的「手臂基座位置」要一起量。

### 2-4 墊子的 0° 射線 = S1 `reference` 的墊子框架

S1（`S1_reach_logger.md` §6，D026）量到一個 `azimuth_offset_deg`，把 FK 的 base 框架綁到
「這張墊子的 0° 射線」。S2 輸出的 `theta_deg` 就是**這個墊子框架**的角度，`x_cm/y_cm` 也是。所以：

- 墊子必須畫出一條明確標「0°」的射線（笛卡兒 +x 軸），所有點相對它擺。
- 墊子邊緣要有一個**實體對位記號**（缺口／對齊線／貼合基座夾具輪廓的形狀），讓現場每次都能把
  墊子擺回同一個旋轉方向——不能只靠目視。
- `--from-summary` 帶入 `reach_summary.json` 時，操作卡要印該檔的 `azimuth_offset_deg` 與
  `azimuth_frame`，並在墊子上把 0° 射線標成「對齊 S1 reference」。
- `reach_summary.json` 的 `azimuth_frame == "base"`（S1 沒記 reference）時：**空白刻度紙可以照印**
  （它本來就不綁 campaign），但**帶 `--placements` 出正式標點墊時拒絕**，印訊息要求先補一次
  S1 `reference` 樣本。

### 2-5 笛卡兒方格 + 極座標疊圖，兩個都要

- **笛卡兒毫米/公分方格**是「拿尺量 x、y」的基底——手標點靠這個才有毫米精度。
- **極座標環（半徑）＋ 射線（方位角）疊在上面**，標數字，供方向感與「這點看起來對不對」的目視檢查。
- 兩者共用同一個原點與同一個 0° 方向。

## 3. 輸入

```
--r-max 40                      # cm；要畫到的最大半徑
--paper a4|single               # a4 = 多張 A4 拼貼；single = 一張大圖（印刷店，2026-09-01 加）
--datum-offset D                # cm；single 必填。pan 軸中心 → C 底盤兩根前端的對位線。
                                #     S2 點平移 x_mat = x_cm − D 到墊子框架（pan 軸在墊子外 x=−D）
--chassis-gap 5.9               # cm；single。C-opening 內寬 → 對位線上兩個刻度的間距
--x-min -3                      # cm；墊子左緣（single 下 = 對位線後方留白，可為小負值）
--margin-mm 10 / --overlap-mm 15  # a4 拼貼用
--grid-mm 5 / --ring-step 5 / --ray-step 15
--out docs/assets/placement_mat_blank.pdf
--placements  a.csv b.csv c.csv # 可選：S2 的三份輸出，畫進 PDF
--from-summary analysis/reach_summary_YYYY-MM-DD.json  # 可選：讀 azimuth_offset_deg + 檢查 frame
--label blank                   # 進檔名與操作卡
--dry-run                       # 只印範圍，不寫檔
```

### `--paper single`（印刷店大圖，2026-09-01）

- **一張 PDF，頁面尺寸 = 圖面實際大小**，座標軸鋪滿整頁 → 100% 列印時 1 data-cm = 1 paper-cm。
- **原點 = C 底盤兩根前端的對位線**（不是 pan 軸 —— 紙進不了 C-opening，會被手臂結構擋住）。
  墊子畫一條粗線在 `x_mat=0`，上下各一刻度在 `±chassis_gap/2`，標「align to L / R C-arm front tip」。
  **兩點接觸 → 前後位置與旋轉都固定。印的是那條線，不是紙邊**（紙的留白可退進 C-slot）。
- pan 軸在墊子外 `x_mat = −D`；極座標環／射線仍以它為圓心畫。
- 點標成短 id：`train_007 → t7`、`eval-open_003 → o3`、`eval-close_010 → c10`。
- 另存 `docs/assets/placement_label_map_<label>.csv`：`short_id, placement_id, x_pan_cm, y_pan_cm, x_mat_cm, y_mat_cm`
  —— eval 記錄用 `placement_id` 時可回查。
- 沒有 mat-frame 的 `--from-summary` 時允許 `--placements`，但墊子上會印「azimuth UNCALIBRATED − base frame」。
- 墊子區域會自動長大到容納所有平移後的點（含內半徑陡角、`r == r_max` 的點）。

## 4. 輸出

**(1) 可列印的墊子 PDF（多張 A4，拼貼）**

每一頁都有：
- **笛卡兒方格**：細格每 `--grid-mm`、粗線每 1 cm、每 5 cm 標數字（沿頁內可見的軸）。
- **極座標疊圖**：半徑環每 `--ring-step`（標數字）、方位角射線每 `--ray-step`（標角度），
  只畫在 `r ≤ r_max` 範圍內。
- 🔴 **一條標「10.0 cm」的校驗尺**（每一頁都要，水平畫在頁內固定位置）。
- **十字對位記號**：四角與各邊中點的十字，相鄰頁在重疊區內的十字座標相同 → 拼貼時十字疊十字。
- **頁碼與格位**：「row R / col C of 3×2」＋ 箭頭指出上/右相鄰頁。
- 落在該頁範圍內的極點（原點）那一頁：**中央十字準星** ＋「對準基座旋轉中心」字樣 ＋
  標「0°」的射線 ＋ 實體對位記號輪廓。

`--placements` 有給時，另外：
- 每個 placement 點畫一個小十字，旁邊印 `placement_id`（含 `train_` / `eval-open_` / `eval-close_`
  前綴），三組用不同記號形狀（空心圓／十字／三角，**不填色**）。
- 點若跨頁邊界，兩頁都畫（在重疊區內）。

**(2) 操作卡 `docs/assets/placement_card_<label>.md`（一頁，現場帶著）**

```
1. 量每一頁的校驗尺 = 10.0 cm（±0.5 mm）？不是就把印表機設 100% 重印。
2. 依十字對位記號拼貼各頁（十字疊十字，不要對紙邊），背面貼膠帶。
3. 墊子極點（0,0）對準基座旋轉中心；0° 射線對準 S1 reference 方向 / 實體對位記號。四角固定。
4. 一次性標點：拿尺照 <label>_*.csv 的 x_cm, y_cm，把每個點畫成小十字＋id。標完拍一張基準照存 docs/assets/。
5. 每一回合：查 placement_id → 把物體放到該十字 → 🔴 把墊子抽走 → 才開始錄。
6. 收工：墊子不要留在場景裡。下次用同一張標好的墊子（別重印、別重標，會有累積誤差）。
```

## 5. 驗收條件

- [ ] PDF 產生後，**程式自己量一次**：把每頁 10 cm 校驗尺的座標換算回 mm，assert = 100.0 mm（±0.1）
- [ ] `--dry-run` 印出的頁數 == 實際 PDF 頁數 == tiling plan 的 tile 數
- [ ] 相鄰兩頁的重疊區：對位十字的世界座標一致（程式自己比對，印出來）
- [ ] 給 `--placements` 時，每個 `placement_id` 都出現在 PDF 上，數量與三份 CSV 總和一致（程式自己數）
- [ ] `azimuth_frame == "base"` 且有 `--placements` → 拒絕出圖，退出碼 2

## 6. 不要做的事

- ✅ **三份清單（`train` / `eval-open` / `eval-close`）畫在同一張墊子上**
  （`[Eric決定]` 2026-08-31，推翻先前「分兩張」的 `[AI推論]`）。理由：同一個實體墊子就是對位基準，
  重印會累積縮放誤差（§2-2）；三份必須在同一個框架下彼此一致。標籤會疊的問題用「一次性手標＋
  記號形狀＋id 索引表」解決（§1、§4），不靠腳本自動排版硬塞。
- ❌ 不要每回合目視內插擺點。點是**一次性**標好的（§1）。
- ❌ 不要用彩色填滿。**墊子若不小心入鏡，越接近純白越不容易變成強烈的背景特徵。**
- ❌ 不要自動重新抽樣。這支腳本只畫 S2 給的點（或什麼都不畫，只出空白刻度紙）。

## 7. 更便宜的替代方案（先評估，可能整支腳本都不必寫）

**`[AI提議]`，待裁決：** 一條釘在基座旋轉中心的**捲尺 ＋ 一張基座處的量角器紙**，
兩個人操作時，一人報 `(r, θ)`、一人擺，可能就夠了，而且**沒有大圖輸出的成本、也沒有縮放風險**。

**判準：擺放重複精度要 ≤ `d_min`/2**（`d_min` 見 S2，目前 2.0 cm → 需 ≤ 1.0 cm）。
**→ 先用捲尺法量 10 次同一個目標點的實際落點散佈，量出來再決定要不要做墊子。**
**這個測試不需要手臂，今天在家就能做**，而且同時能驗證 §1 說的「一次性手標誤差」有多大。
