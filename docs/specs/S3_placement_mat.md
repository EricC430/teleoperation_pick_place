# S3 — 擺放對位（極座標墊產生器）

**目標檔案：`scripts/make_placement_mat.py`**
**正本依據：`docs/decisions.md` D023 第 3 支腳本**

---

## 1. 這支腳本要解決的問題

S2 抽出了 `(r, θ)`。**問題是怎麼把實體物件真的放在那個座標上，而且每次都放得一樣。**
放不準 → 「seeded placement」這件事就沒有意義，跨模型可比性也就沒有了。

## 2. 🔴 三個會毀掉資料的地雷

### 2-1 墊子留在畫面裡＝它變成背景常數

D023 原文：**「A mat left in frame becomes part of the background — a scene constant baked into
every demo.」**
→ **用墊子把物體擺好，然後把墊子抽走，再開始錄。** 每回合約 10 秒。
→ 腳本輸出的操作卡上**第一行就要印這句**。

### 2-2 印表機會縮放

A4「實際大小」列印在多數驅動裡不是預設值。縮放 96% 的墊子會讓每一個點都系統性偏內。
→ **每一頁都要印一條標示「10.0 cm」的校驗尺**，操作卡第一步是「用捲尺量這條線，不是 10.0 就重印」。

### 2-3 原點對不準比刻度不準更嚴重

墊子的極點必須對到**手臂基座的旋轉中心**，不是基座外殼的邊。
→ 墊子中央要有十字準星與一段說明；`docs/experiment_spec.md` §3 的「手臂基座位置」要一起量。

## 3. 輸入

```
--placements configs/placements/<label>_train.csv    # S2 的輸出
--r-inner 20 --r-outer 30
--theta-min -35 --theta-max 88
--out docs/assets/placement_mat_<label>.pdf
--paper a4                    # a4 拼貼；若能大圖輸出則 --paper a1 單張
--ring-step 5                 # 半徑環間距 cm
--ray-step 10                 # 方位角射線間距 度
```

## 4. 輸出

**(1) 可列印的墊子 PDF**
- 半徑環（每 `--ring-step` 一圈，標數字）＋ 方位角射線（每 `--ray-step` 一條，標角度）
- **每一個 placement 點畫一個小十字，旁邊印 `placement_id`**
- 中央十字準星 ＋「對準基座旋轉中心」字樣
- 🔴 **每頁一條 10.0 cm 校驗尺**
- A4 拼貼時：頁碼、拼接對齊記號、重疊邊界

**(2) 操作卡 `docs/assets/placement_card_<label>.md`（一頁，現場列印帶著）**

```
1. 量校驗尺 = 10.0 cm？不是就重印。
2. 墊子極點對準基座旋轉中心，四角貼紙膠帶固定。
3. 拍一張基準照（墊子＋基座），存 docs/assets/。
4. 每一回合：查 placement_id → 把物體放到該十字 → 🔴 把墊子抽走 → 才開始錄。
5. 收工：墊子不要留在場景裡；下次要用同一張（別重印，重印會有累積誤差）。
```

## 5. 驗收條件

- [ ] PDF 用 `pypdf`/`reportlab` 產生後，**程式自己量一次**：把 10 cm 尺的座標換算回 mm，assert 正確
- [ ] 每個 `placement_id` 都出現在 PDF 上，數量與 CSV 一致（程式自己數，印出來）
- [ ] A4 拼貼模式下，相鄰頁的重疊區內容一致
- [ ] `--dry-run` 只印頁數與涵蓋範圍

## 6. 不要做的事

- ❌ 不要把 train 與 eval 印在同一張墊子上。**兩份清單分兩張**，避免現場拿錯。
- ❌ 不要用彩色填滿。**墊子若不小心入鏡，越接近純白越不容易變成強烈的背景特徵。**
- ❌ 不要自動重新抽樣。這支腳本只畫 S2 給的點。

## 7. 更便宜的替代方案（先評估，可能整支腳本都不必寫）

**`[AI提議]`，待裁決：** 一條釘在基座旋轉中心的**捲尺 ＋ 一張基座處的量角器紙**，
兩個人操作時，一人報 `(r, θ)`、一人擺，可能就夠了，而且**沒有大圖輸出的成本、也沒有縮放風險**。

**判準：擺放重複精度要 ≤ `d_min`/2**（`d_min` 見 S2）。
**→ 先用捲尺法量 10 次同一個目標點的實際落點散佈，量出來再決定要不要做墊子。**
**這個測試不需要手臂，今天在家就能做。**
